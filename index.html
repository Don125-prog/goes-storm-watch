About

This tool performs binary classification of convective (cumulonimbus) clouds from GOES-16 ABI infrared satellite imagery. The model is a ResNet-18 trained on 5 IR channels (C07, C09, C13, C14, C15) using combined Cloud Top Phase and brightness temperature labels.

Technical details
  • Input: 5 IR channels, 64×64 patches, stride 48
  • Label: Phase == Ice AND CMI_C13 < 220 K
  • Architecture: ResNet-18, conv1 adapted for 5 channels
  • Performance: Precision 91%, Recall 82%, F1 86%, AUC 0.993
  • Inference: ONNX Runtime Web (runs entirely in your browser)
